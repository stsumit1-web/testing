# Release Notes - Version 1.1

## What's New in Version 1.1

🎨 **Enhanced Transaction Management**

✅ **Edit & Delete Transactions**
- Tap any transaction to expand and reveal action buttons
- Beautiful Edit and Delete buttons with smooth animations
- Confirmation dialog before deleting transactions
- Full edit dialog with amount, category, and description changes

✅ **Expense ↔ Savings Toggle**
- Convert any expense to savings with a tap
- Toggle switch in the edit dialog (for expenses only)
- Visual indicator shows current transaction type
- Automatic category naming with (Savings) or (Expense) suffixes

✅ **Unique Category Switcher**
- New animated glassmorphic toggle in Analytics
- Fun emoji icons (💸 for Expenses, 🏦 for Savings)
- Bouncy spring animation when switching
- Color-coded sliding indicator (red → green)

✅ **Visual Improvements**
- Blue highlighting for savings transactions
- "Savings" badge on converted transactions
- Expanded transaction list height (no more cut-off)
- Better spacing between transaction items
